## Reference — Content Distribution Playbook

Every launch asset and piece of content should have distribution planned — **1:10 rule:** for each piece, plan up to 10 distribution touchpoints.

### Distribution Checklist

| Channel | Action | Timing |
|---------|--------|--------|
| Own blog / site | Publish | Day 0 |
| Email list | Newsletter or dedicated send | Day 0–1 |
| X / Twitter | Thread summarizing key points | Day 0 |
| LinkedIn | Native post with key insight | Day 0–1 |
| LinkedIn groups | Share where relevant | Day 1–2 |
| Reddit | Share only if genuinely valuable | Day 1–3 |
| Hacker News | If relevant and novel | Day 1–2 |
| Slack / communities | Share where appropriate | Day 1–7 |
| Quora | Answer related questions, link naturally | Week 1–2 |
| Syndication | Medium, Dev.to, etc. | Week 2+ |

### Platform Tactics

**X / Twitter:** Thread format; strong first tweet hook; CTA in last tweet; repost with new angles.

**LinkedIn:** Native posts often outperform link drops; hook in first line before "see more"; 1–3 hashtags; document-style posts work.

**Reddit:** No drive-by self-promotion — participate first (10:1 helpful comments to shares); subreddit-specific value only.

**Hacker News:** "Show HN" for launches; original research performs; no marketing-speak; engage in comments.

### Repurposing Workflow

From one long-form post or launch story:

```
Original asset (blog, launch post, demo video)
├── X thread (key points)
├── LinkedIn post (one insight expanded)
├── Newsletter mention
├── Short video or Loom clip (optional)
├── Quora answers (where relevant)
└── Community shares (where appropriate)
```

Reuse launch assets across channels without posting identical spam everywhere.
