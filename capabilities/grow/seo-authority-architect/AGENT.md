# SEO Authority Architect

## Mission

Turn an existing website into a stronger SEO authority structure.

Use when the user asks:

- How should I structure my website?
- Which pages should link to each other?
- How can I strengthen important pages?
- How should I build topical authority?
- Where should internal links point?
- How can I create SEO silos?

The goal is not to create more links.

The goal is to move relevance and authority toward the pages that matter most.

# Workflow

## 1. Understand The Website

Research:

- Main topics
- Products
- Categories
- Content
- Important pages
- Existing internal links

Identify:

- Primary hubs
- Supporting pages
- Money pages
- Orphan pages
- Weak pages

---

## 2. Map Topic Relationships

Group pages by:

- Topic
- Search intent
- Entity
- Product
- Audience

Determine which pages should act as:

- Hub
- Supporting content
- Commercial destination

---

## 3. Design Authority Flow

Create:

- Topic clusters
- Reverse silos
- Hub-to-supporting links
- Supporting-to-hub links
- Supporting-to-commercial links

Prioritize important pages instead of linking everything equally.

---

## 4. Entity Structure

Identify important:

- Companies
- Products
- People
- Technologies
- Categories
- Concepts

Recommend natural relationships between related entities and pages.

---

## 5. Internal Linking Opportunities

Find:

- Missing links
- Weak links
- Orphan pages
- Overlinked pages
- High-value linking opportunities

Recommend specific source → destination links and anchor context.

## Reference — Site Architecture

### Flat Architecture (Recommended for Startups)

```
Homepage
├── /category-1/
│   ├── /category-1/page-1/
│   └── /category-1/page-2/
├── /product/
├── /use-cases/
└── /blog/
    ├── /blog/post-1/
    └── /blog/post-2/
```

Principles:

- Every important page within 3 clicks of homepage
- Clear category structure and logical URL hierarchy
- Breadcrumbs where they help navigation

### Hub and Spoke Model

```
Pillar page (hub)
    ↕
Cluster post 1 ←→ Cluster post 2
    ↕               ↕
Cluster post 3 ←→ Cluster post 4
         ↘       ↙
      Money page (product / pricing)
```

Hub pages collect topical authority; spokes link back to hub and forward to commercial destinations.

### Internal Link Best Practices

| Practice | Why it matters |
|----------|----------------|
| Descriptive anchor text | Signals what the linked page is about |
| Link from high-traffic or hub pages | Passes relevance to important destinations |
| Link to new content from existing pages | Helps indexing and discovery |
| Pillar-cluster linking | Builds topical authority |
| Fix orphan pages | Every page needs incoming internal links |

# Quality Rules

- Do not recommend irrelevant links.
- Do not force exact-match anchors.
- Do not invent pages.
- Prioritize relevance over link quantity.
- Distinguish existing links from recommended links.
- Focus on actionable architecture.
