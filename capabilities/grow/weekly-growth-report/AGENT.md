# Weekly Growth Report

## Mission

Produce a **short weekly operating report** — what changed, what matters, one next action.

Use when the user asks:

- Weekly SEO / growth report
- What should I focus on this week?
- Summarize my site performance and gaps
- Recurring growth check-in

Designed to run on a **schedule** (e.g. every Monday) with the same structure each time so founders can compare week over week.

This makes Founder OS feel like an operating rhythm, not a one-off toolbox.

---

# Input

## Required

- Website URL

## Optional

- Search Console export or summary (user-provided)
- Analytics summary (sessions, top pages — user-provided)
- Previous weekly-growth-report output (for deltas)
- Current priorities (launch, content, technical fixes)
- Competitor URL for light context
- Customer voice or positioning updates from the week

Never invent metrics.

If no data is provided, produce a **research-based gap report** and label all traffic sections as "data needed."

---

# Workflow

## 1. Snapshot The Week

When user supplies data, summarize:

- Organic clicks / impressions trend (direction only if numbers given)
- Top gaining and losing pages (if known)
- Notable indexation or crawl issues reported by user
- Published or updated content this week

If no data: ask what they can paste next time; still deliver gaps and one action from public site review.

---

## 2. Top Pages And Health

Interpret top pages (or main nav + blog index if no analytics):

- Which pages likely drive signups or intent
- Stale or thin pages among top traffic
- Technical red flags (only if technical-seo-audit was run or user reported issues)

Keep interpretation brief.

---

## 3. New Gaps

Identify **this week's** opportunities:

- Content gaps vs competitors (light scan — not full content-gap skill)
- Queries or topics implied by site but not covered
- Launch or distribution follow-ups unfinished
- Voice-of-customer themes to address (if mining output exists)

Limit to **3 gaps** ranked by impact.

---

## 4. One Recommended Next Action

Choose **exactly one** primary action for the coming week:

- Runnable in a few hours to a few days
- Mapped to a capability when relevant (e.g. technical-seo-audit, content-refresh-and-repurpose, seo-opportunity)

Explain why this action beats alternatives **this week**.

Optional secondary action only if trivial (≤30 min).

---

## 5. Compare To Last Week (If Prior Report Exists)

Note:

- What was recommended last time
- Done / not done (user-stated)
- Whether metrics moved (if data provided)

# Quality Rules

- No fake traffic, rankings, or conversion rates.
- Same report skeleton every week for comparability.
- Founder-facing — no CMO dashboard sprawl.
- One primary action — resist laundry lists.
- Skip backlinks, programmatic SEO, and paid media deep dives.
