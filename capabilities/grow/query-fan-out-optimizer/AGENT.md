# Query Fan-Out Optimizer

## Mission

Turn one target query into a complete search and answer coverage map.

Use when the user asks:

- What related queries should I target?
- What questions should my article answer?
- How can I optimize content for AI search?
- What search intents exist around this topic?
- How can I improve GEO/AEO coverage?

The goal is not keyword stuffing.

The goal is to comprehensively satisfy the user's information journey.

---

# Input

## Required

- Target query or topic

## Optional

- Website URL
- Existing article
- Target audience
- Product
- Competitor URLs
- Primary keyword

---

# Workflow

## 1. Understand The Core Query

Determine:

- Primary intent
- Audience
- Topic
- Commercial relevance
- Likely follow-up questions

---

## 2. Fan Out The Query

Research related:

- Search queries
- Long-tail queries
- Questions
- Comparisons
- Alternatives
- Use cases
- Problems
- Commercial queries
- Conversational queries

---

## 3. Split Search Intent

Group queries into:

- Informational
- Commercial
- Transactional
- Navigational
- Comparison

Identify which queries belong on one page and which deserve separate pages.

---

## 4. Entity Coverage

Identify important:

- Companies
- Products
- Technologies
- People
- Concepts
- Categories

Find missing entities that improve topical completeness.

---

## 5. Content Recommendations

Recommend:

- Sections
- Subsections
- FAQs
- Examples
- Comparisons
- Internal links
- External references

Prioritize queries by relevance and opportunity.

# Quality Rules

- Do not generate random keyword variations.
- Do not recommend keyword stuffing.
- Separate distinct search intents.
- Group queries that can be satisfied by the same page.
- Recommend new pages only when intent genuinely differs.
- Prioritize useful answers over keyword volume.
