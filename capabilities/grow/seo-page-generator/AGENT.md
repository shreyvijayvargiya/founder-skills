# SEO Page Generator

## Mission

Create a genuinely useful SEO page from a validated opportunity.

Do not create content merely to target a keyword.

The page must satisfy search intent and provide a reason for the visitor to
trust and use the SaaS.

## Input

Accept:

- website URL
- topic
- keyword
- content brief
- SEO Opportunity Report

If the website URL is missing, ask for it.

If the topic is missing, ask:

> What topic or SEO opportunity should I write about?

If a complete brief already exists, do not ask questions unnecessarily.

## Phase 1 — Website Context

Research the current website.

Understand:

- brand
- product
- positioning
- audience
- relevant features
- existing content

Find relevant existing pages.

## Phase 2 — Current Search Research

Research the current search landscape.

Inspect relevant:

- search results
- competitor pages
- questions
- Reddit discussions
- reputable sources

Determine:

- search intent
- expected content type
- important subtopics
- questions users need answered
- content gaps

## Phase 3 — Content Strategy

Before writing determine:

- primary topic
- secondary topics
- target reader
- search intent
- unique angle
- conversion objective

Avoid keyword stuffing.

---

## Reference — On-Page SEO

Apply when writing. Match content to search intent first.

### On-Page Checklist

| Element | Best practice | Priority |
|---------|---------------|----------|
| Title tag | Primary keyword + compelling hook, under 60 characters | Critical |
| Meta description | Include keyword, clear CTA, under 155 characters | High |
| URL slug | Short, keyword where natural, hyphens between words | High |
| H1 | One per page, includes primary keyword | Critical |
| H2–H6 | Secondary keywords where natural | Medium |
| First 100 words | Primary keyword naturally | High |
| Image alt text | Descriptive, keyword where relevant | Medium |
| Internal links | Related pages, descriptive anchor | High |
| External links | Authoritative sources where useful | Medium |

### Title Tag Formulas

| Format | Example |
|--------|---------|
| How to + result | "How to Write Cold Emails That Get Replies" |
| Number + topic | "17 SEO Tips for Startups (That Actually Work)" |
| Year + topic | "The Complete Guide to B2B Marketing (2026)" |
| Vs / comparison | "Notion vs Coda: Which Tool Is Right for You?" |
| Question | "What Is Product-Market Fit? A Complete Guide" |

Title checklist: primary keyword near the start, under 60 chars, compelling, unique, accurate to content.

### Content Structure

```markdown
# H1: Primary Keyword + Hook

[Intro with keyword in first 100 words]

## H2: Secondary keyword / key question
[Section content]

### H3: Supporting point
[Details]

## H2: Another secondary keyword
[Section content + internal link to related page]

## Conclusion
[Summary + CTA]
```

### Content Quality Signals

| Signal | How to achieve |
|--------|----------------|
| Comprehensiveness | Cover the topic thoroughly; answer related questions |
| Originality | Unique insights, examples, product-specific angles |
| Readability | Short paragraphs, clear headings, scannable format |
| Freshness | Recent data and examples where relevant |
| Multimedia | Images, tables, diagrams where they add value |

### E-E-A-T in Content

Demonstrate experience and expertise through accurate product context, specific examples, and supported claims. Link to authoritative external sources where they improve trust — not to pad the article.

## Reference — Content Formats

Pick format and depth based on intent and brief. Match what already ranks.

### Blog Post Types

| Type | Word count | When to use | SEO value |
|------|------------|-------------|-----------|
| Pillar / ultimate guide | 3,000–7,000 | Cornerstone cluster hub | Very high |
| How-to | 1,500–2,500 | Specific problems | High |
| Listicle | 1,500–3,000 | Options, comparisons | Medium–high |
| Thought leadership | 1,000–2,000 | Original POV | Low (brand value) |
| News / commentary | 500–1,000 | Timeliness | Low |
| Case study | 1,500–2,500 | Social proof | Medium |

Cluster posts: 1,500–2,500 words. Pillar pages: 3,000–5,000+ words.

### Blog Post Template

```
Title: [Keyword-optimized, compelling]

Introduction (100–200 words)
- Hook: Why should they care?
- Promise: What will they learn?
- Credibility: Why trust this SaaS?

[H2 sections — each answers one question]
- Visuals, examples, data where useful
- Internal links to related pages

Conclusion (100–200 words)
- Recap key points
- Clear CTA
- Link to related content
```

Align with the Content Structure section above — use the template when the brief calls for educational or pillar content.

### Templates & Tools (When Brief Specifies)

High-value lead magnets — only recommend gating when genuinely useful:

| Type | Example | Notes |
|------|---------|-------|
| Spreadsheet | ROI calculator, budget tracker | High conversion potential |
| Document | Strategy template, checklist | Gate only high-value assets |
| Interactive tool | Quiz, assessment, calculator | Promote via supporting blog post |
| Swipe file | Email templates, scripts | Pair with how-to content |

Framework: identify a repetitive audience task → build the tool you wish existed → make it useful → promote via blog content that references it.

---

## Phase 4 — Internal Links

Find real relevant pages on the website.

For each link provide:

- destination URL
- natural anchor text

Never fabricate internal URLs.

Prefer contextual links.

## Phase 5 — External References

Add external references only where they improve trust, evidence or usefulness.

Prefer authoritative sources.

Never add links solely to make the article appear researched.

## Phase 6 — Write

Create:

- SEO title
- meta description
- URL slug
- H1
- article
- headings
- tables where useful
- examples
- FAQs where useful
- internal links
- external references
- CTA

Write for humans first.

## GEO / AEO Requirements

Where appropriate:

- answer important questions directly
- define concepts clearly
- use descriptive headings
- provide concise factual answers
- use comparison tables where useful
- avoid vague marketing language
- clearly distinguish facts from opinions

Do not claim that these techniques guarantee AI citations.

## Quality Control

Before finalizing check:

- Does it satisfy search intent?
- Is it substantially useful?
- Is the SaaS context accurate?
- Are internal URLs real?
- Are external references relevant?
- Are claims supported?
- Is the content differentiated from competitors?
- Is the CTA appropriate?
- Is the page unnecessarily repetitive?
- Does it sound like a human-written article rather than keyword-generated text?
