# Internal Link Optimizer

## Mission

Improve how search engines and users navigate a SaaS website through better internal linking.

Use when the user asks:

"Optimize internal links."

"Find orphan pages."

"How should I connect my SEO pages?"

INPUT

Required:

SaaS URL

Optional:

Sitemap
Existing SEO/content plan
Specific pages to optimize
WORKFLOW
1. Crawl the site

Use available browser/search/crawl capabilities.

Map:

URLs
Page types
Titles/H1s
Existing internal links
Navigation
Breadcrumbs
Important content
2. Build the page graph

Group pages into:

Homepage
Category
Product
Feature
Use case
Industry
Integration
Competitor
Blog
Resource
Tool/template

Identify:

Orphan pages
Weakly linked pages
Over-linked pages
Important pages with few internal links
Pages with strong authority that can distribute links
3. Determine relationships

For each important page identify:

Parent page
Related pages
Supporting content
Commercial destination
Relevant contextual links
4. Recommend links

Prioritize contextual links over arbitrary navigation links.

For each recommendation provide:

Source URL
Destination URL
Suggested anchor
Reason
Placement/context

Never invent URLs.

5. Anchor strategy

Use natural descriptive anchors.

Avoid repetitive exact-match anchor text.

---

## Reference — Internal Linking Playbook

| Practice | Why |
|----------|-----|
| Descriptive anchor text | Tells Google and users what the destination covers |
| Link from hubs and high-traffic pages | Distributes authority to money pages |
| Link new content from related existing pages | Speeds indexing and discovery |
| Pillar ↔ cluster links | Establishes topic authority |
| Fix orphan pages | Pages with zero incoming internal links underperform |

Hub and spoke: pillar page at center, cluster posts link to pillar and to each other where relevant, all paths should reach commercial pages when appropriate.

Anchor mix target (healthy profile): favor branded and descriptive anchors; keep exact-match keyword anchors under ~15% of internal links on a given page.

RULES
Only use verified URLs.
Links must be contextually relevant.
Do not over-optimize anchors.
Prioritize important pages and user navigation.
Do not add links merely to increase link count.
