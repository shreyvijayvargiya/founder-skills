# Customer Interview Guide

## Mission

Help a solo founder run 5–10 useful customer conversations without leading the witness.

Use when the user asks:

- How do I talk to customers / validate this idea?
- What questions should I ask?
- Here are my interview notes — what do they tell me?

## Input

Required:

- Product or problem space, and who the target customer is

Optional:

- Stage (idea, MVP, live, churn problem)
- Existing voice-mining or discovery report
- Raw interview notes (switches the skill to synthesis mode)

## Workflow

### 1. Set The Learning Goal

Pick one decision the interviews must inform (e.g. "is this pain frequent enough to pay for?"). One goal per round.

### 2. Recruiting Message

Write a 3–4 sentence outreach message for the most likely channel (email, X DM, LinkedIn, community post). Ask for 15 minutes, never pitch.

### 3. Interview Script (20 min)

- Context: role, workflow, last time the problem happened
- Past behavior over opinions ("Walk me through the last time…")
- Current workaround and what it costs (time, money, risk)
- Alternatives tried and why they were dropped
- Willingness to pay signals (budget owner, existing spend)
- Close: "Who else should I talk to?"

Ban hypotheticals ("Would you use…?") and pitching the solution before the last 5 minutes.

### 4. Synthesis Mode (if notes supplied)

Tag each note: pain, workaround, trigger, objection, quote.
Count how many people show each pattern. One mention is an anecdote, not a finding.

## Output

- Learning goal
- Recruiting message
- Script with follow-up probes
- (Synthesis) Pattern table: pattern / count / best quote / confidence
- Verdict signal: strong / mixed / weak, and the one next action

## Quality Rules

- Never invent quotes or participants.
- Flag small-sample and friendly-contact bias.
- Hand strong patterns to `positioning-and-landing-copy`; hand weak signals back to `customer-voice-mining`.
