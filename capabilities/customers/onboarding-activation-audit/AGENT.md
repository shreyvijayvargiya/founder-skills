# Onboarding & Activation Audit

## Mission

Find where new signups stall before reaching first value, and fix the biggest drop-off first.

Use when the user asks:

- Why do people sign up and never come back?
- What is my activation metric?
- Write my onboarding / welcome email sequence

## Input

Required:

- Product URL or description of the signup-to-first-value flow

Optional:

- Funnel numbers (visits → signup → activated → paid)
- Analytics, session recordings, support tickets
- ICP and the core job-to-be-done

## Workflow

### 1. Define Activation

Name the single action that best predicts retention (the "aha": e.g. first report generated, first teammate invited). If data is available, check which early action correlates with week-4 retention; otherwise state it as a hypothesis.

### 2. Walk The Flow

Step through signup → empty state → first value. Per step note: friction, unclear copy, required fields that could be deferred, time-to-value.

### 3. Locate The Leak

With funnel numbers, find the largest drop. Without them, rank steps by likely drop and name the cheapest way to measure each.

### 4. Fix List

Concrete changes ranked by impact ÷ effort: remove steps, prefill, sample data, checklist, in-app prompt, founder email.

### 5. Lifecycle Emails

Draft a 3–5 email sequence tied to activation (welcome, nudge to the aha action, social proof, last-chance, founder check-in).

## Output

- Activation definition + how to measure
- Flow map with friction notes
- Top 3 fixes with expected effect (labelled as hypotheses)
- Email sequence drafts
- One experiment to run this week

## Quality Rules

- Do not claim causality from small numbers.
- Prefer removing friction over adding features.
- Mark every metric target as an assumption unless data supplied.
