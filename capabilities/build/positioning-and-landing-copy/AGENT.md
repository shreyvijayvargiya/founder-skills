# Positioning And Landing Copy

## Mission

Turn research into **shippable landing page copy** — not another strategy memo.

Use when the user asks:

- Write my landing page
- What's my value prop and hero?
- Turn discovery into homepage copy
- I need sections and a CTA for my SaaS

Ground copy in prior outputs when available:

- saas-discovery
- customer-voice-mining
- market-intelligence / competitor-intelligence
- micro-saas-builder scope

If only a URL exists, do brief discovery first — do not write generic SaaS filler.

---

# Input

## Required

- Product URL **or** structured discovery output (product, ICP, problem, differentiator)

## Optional

- Customer voice clusters and exact phrases
- Business motion (PLG vs sales-led)
- Primary CTA (signup, trial, demo, waitlist)
- Competitor positioning to contrast (not trash-talk)
- Brand tone (direct, friendly, enterprise, technical)
- Page type (homepage, use-case page, waitlist)

---

# Workflow

## 1. Extract Positioning Spine

Define:

- One-line value proposition
- Primary ICP (one sentence)
- Core problem (in customer language)
- Primary outcome
- Key differentiator ( provable, not hype )
- Reason to believe (features, proof type, social proof angle)
- Primary CTA and secondary CTA

Reject vague claims ("all-in-one platform") unless the product truly owns a category.

---

## 2. Message Hierarchy

Order messages for a landing page:

1. Hero — pain + outcome + differentiation
2. Social proof strip (placeholders if none provided — label as TODO)
3. Problem agitation (3 bullets in customer words)
4. Solution / how it works (3 steps max)
5. Key capabilities (outcome-led, not feature dump)
6. Use cases or personas (optional)
7. Objection handling (FAQ or short section)
8. Final CTA block

Match depth to motion:

- PLG: speed, self-serve, try free
- Sales-led: ROI, security, demo, trust

---

## 3. Write Page Copy

Deliver ready-to-paste blocks:

- Page title (browser tab)
- Meta description (~155 chars)
- Hero: headline, subhead, primary CTA button label, secondary link label
- Section headlines and body (short paragraphs, scannable bullets)
- FAQ (3–5 questions from real objections when voice-mining exists)
- Footer CTA repeat

Use customer phrases from voice-mining when provided.

Avoid:

- Jargon the ICP does not use
- Fake metrics, logos, or testimonials
- Competitor naming unless user requested comparison page

---

## 4. Variants (Optional)

If useful, provide:

- 2 hero headline options (pain-led vs outcome-led)
- 1 shorter variant for waitlist / pre-launch

# Quality Rules

- Copy must reflect inputs — no generic SaaS template if product is specific.
- Mark assumed proof as [TODO] — never invent customers or metrics.
- Keep sentences short; founders should paste into Webflow, Framer, or HTML.
- One primary CTA per page unless user asked for dual motion.
